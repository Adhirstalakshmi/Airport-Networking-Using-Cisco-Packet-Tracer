
# Airport Networking Using Cisco Packet Tracer

## 📌 Project Overview

This project focuses on designing and implementing a computer network infrastructure for an airport using Cisco Packet Tracer.

The network connects different airport departments and enables secure and efficient communication between them.

## 🎯 Objectives

- Design a structured airport network.
- Connect multiple departments through a centralized network.
- Implement VLANs for network segmentation.
- Configure dynamic routing using OSPF.
- Provide automatic IP address allocation using DHCP.
- Configure DNS services.
- Implement network security using Access Control Lists (ACL).

## 🛠️ Technologies Used

- Cisco Packet Tracer
- VLAN
- OSPF
- DHCP
- DNS
- ACL
- Networking Devices (Routers and Switches)

## 🏢 Network Departments

The airport network includes:

1. Administration Department
2. Security Department
3. Check-in Department
4. Baggage Department
5. Operations Department
6. Guest Network
7. Weather Department

## ⚙️ Key Features

- VLAN-based network segmentation.
- Inter-department communication.
- OSPF dynamic routing between routers.
- DHCP for automatic IP configuration.
- DNS server configuration.
- ACL for controlling network traffic.
- Weather monitoring using a temperature sensor.

## 📂 Project Files

- `PROJECT PEP AIRPORT.pkt` – Cisco Packet Tracer simulation file.
- `Projects Template AIRPORT FINAL.pdf` – Project documentation and report.

## ▶️ How to Run the Project

1. Download the `.pkt` file from this repository.
2. Install and open Cisco Packet Tracer.
3. Open the downloaded project file.
4. Explore the network topology and configurations.
5. Test connectivity between network devices.
